# Student-Habits-Performance-dataset-.Data-Analysis
Student Habits Performance dataset 
📊 Student Habits & Performance Analysis
📌 Overview

This project presents a descriptive analytics study of student habits and their academic performance. The goal is to summarize how different behaviors and characteristics are distributed and how they relate to exam outcomes.

🎯 Objectives
Provide a clear overview of student data
Analyze Average Exam Score and Student Distribution
Understand how performance varies across key factors
🔑 Key Performance Indicators (KPIs)
Average Exam Score
Total Number of Students
📂 Dataset Description

The dataset includes student-level information such as:

Exam scores
Study hours
Attendance
Gender and age
Sleep, exercise, and mental health
Social habits and learning environment

Each row represents one student.

❓ Business Questions

This analysis answers descriptive questions such as:

What is the overall distribution of exam scores?
How are students distributed across different categories?
How does average exam score vary by:
Study hours
Attendance
Gender
Age
Lifestyle factors (sleep, exercise, mental health)
📊 Deliverables
1. Excel Dashboard
KPI cards (Average Score, Total Students)
Charts for performance across dimensions
Pivot tables and slicers for filtering
2. Report (Word / PowerPoint)
Business brief
Key descriptive insights
Visualizations from the dashboard
📈 Analysis Type

This project uses Descriptive Analytics only:

No predictions
No machine learning
Focus on summarizing and presenting data clearly
🛠 Tools Used
Microsoft Excel (Pivot Tables, Charts, Dashboard)
Data Cleaning & Categorization
📎 Conclusion

This project provides a simple and structured view of how student habits and characteristics are distributed and how they relate to academic performance, helping stakeholders better understand student behavior
